# line11-dual-v1 导出格式

状态：训练端导出、独立整数参考与 C++/WASM 加载器及增量推理均已实现。
该文件描述的张量和数值语义由各运行时共用，不兼容 Rapfi 的权重二进制。

## 特征与计算

每个点按 `(dx,dy)=(1,0),(0,1),(1,1),(1,-1)` 提取中心前后各 5 格。
棋盘外作为独立边界，输入三平面分别为己方、对方、边界；映射网络使用
5 层不补边的 kernel=3 Conv1d，前四层接 ReLU，最后一层接 tanh。
前两方向共享 hv 映射，后两方向共享 diag 映射。映射权重不进入推理包，
通过枚举所有有效局部棋形生成表。

按左侧有效格数 `left=0..5`、右侧有效格数 `right=0..5` 的顺序排列子表。
子表长 `3^(left+right+1)`，累计总长 397488。每个有效格以空/己/对=0/1/2
编码，沿负方向到正方向按三进制低位到高位排列。两种视角查询同一套权重，
通过改变棋子相对颜色取得不同表索引。

表项按 256 缩放，四方向相加后截断至 `[0,256]`。全通道使用带零填充的
3×3 depthwise 卷积，权重和 bias 按 1024 缩放。偏置乘以 256 后参与累加，
结果除以 1024 并舍入，再截断至 `[0,256]`。

按行棋方视角、对手视角拼接特征。全局平均和九个区域平均均舍入至整数，
区域边界为 `floor(k*size/3)`，九块按行排列且互不重叠。
value 输入依次为全局、九个区域、执黑标志和 `size/20`；后两者也按 256 缩放，
末尾补零使输入宽度为 16 的倍数。value_hidden 接截断激活，value_out 输出三个
WDL logits，顺序为胜、和、负。

policy_local 接收每个点的双视角特征；policy_global 接收全局平均及同样的
执黑/尺寸上下文（同样补零对齐）。二者的线性输出相加后舍入和截断，
再由 policy_out 产生各点 logit。占据位置对外置为 `-1e9`。
policy 排序不改变规则合法性。

所有激活量化采用最近偶数舍入，整数参考通过商和余数处理正负数。
头部权重与 bias 限制在 `[-8,8]` 再按 1024 缩放。整数激活为 0..256；
线性累加使用 int64，激活层除以 1024，最终 logits 除以 `256*1024`。
允许宽度上限 1024，最宽输入不超过 20496，因此这些累加边界在 int64 内。
训练使用同样的截断与直通梯度量化。运行时对 WDL logits 做稳定 softmax，
搜索分值为 `round(600 * atanh(clamp(P(win)-P(loss), -0.999999, 0.999999)))`，
相对于行棋方且与搜索的 ±100000 杀棋分数隔离。policy logits 用于安静着排序，
即时成五、防守及上一轮主变化优先。分值不是胜率或 Elo。

## 二进制

全部整数使用 little-endian，无隐含对齐填充。文件以 Python struct 格式
`<8s12I` 的 56 字节头开始：

1. magic：8 字节 `GMLINE1` 加 NUL。
2. 格式版本 1、特征版本 1。
3. mapping_width、channels、value_hidden、policy_hidden。
4. activation_scale=256、weight_scale=1024。
5. 棋盘尺寸、规则（0=freestyle，1=standard）。
6. 张量数 14、单表棋形数 397488。

随后按 `export.tensor_shapes()` 的固定顺序保存 14 个张量。每个张量先写
`<32s6I` 的 56 字节描述符：NUL 填充名称、维数、缩放因子、四个维度
（未使用的维度写零），随后立即写连续 C-order 的 int16 数据。

顺序为两套 codebook，然后依次写 spatial、value_hidden、value_out、
policy_local、policy_global、policy_out 各自的 weight 和 bias。
value/policy 头部宽度由上面的上下文补零规则决定。
加载器必须逐个校验名称、维度、尺寸、缩放和文件边界，并拒绝尾部多余字节。

独立 manifest 提供 SHA-256、字节数、结构配置和结构摘要、规则、棋盘尺寸、
源检查点和数据清单摘要、训练步数与运行时兼容状态。新导出保持
`runtimeCompatible=false`，直到该模型的 C++/WASM 推理完成验证。
当前加载器额外限制单模型文件不超过 512 MiB；浏览器内存上限与常驻占用不同，
实际加载成本见 [运行时说明](../docs/nnue-runtime.md)。
